## 💻 Running the Portfolio Locally

To run this portfolio on your local machine:

### 1. Clone the repository

```bash
git clone git@github.com:KevinJ3259/kevin-jordan-portfolio-v2.git
```

### 2. Enter the project directory

```bash
cd kevin-jordan-portfolio-v2
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Vite will display the local development URL in the terminal, typically:

```text
http://localhost:5173/
```

Open the URL in your browser.
